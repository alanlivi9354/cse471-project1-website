How it works

The additive instrument adds sine waves using the amplitudes in harmonics. The first value controls the fundamental, the second controls twice that frequency, and so on. My scores use eight values. Frequencies at or above half the sample rate are left out.

harmonicsEnd gives a second set of amplitudes. Each amplitude gradually changes from its starting value to its ending value during the note. If that field is missing, the sound keeps the starting values. The sum is divided by a fixed amplitude total to control its level.

The ADSR envelope controls attack, decay, sustain, and release using those four XML fields. Each note has its own oscillator and envelope, so notes can overlap. vibrato sets the fractional pitch-change depth, and vibratoRate sets its speed in Hz. All harmonics follow that pitch change.

In the song, additive plays the melody and some longer harmony notes. The notes use cross-fading, with vibrato added in later sections. The longer notes also overlap and use longer envelopes.
