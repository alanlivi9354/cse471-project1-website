How it works

The wavetable instrument makes a 2048-sample wave cycle before a note starts. The wave field chooses 0 = sine, 1 = square, 2 = sawtooth, 3 = triangle, or 4 = soft reed. The tables are made by adding harmonics below half the sample rate.

The program reads between samples with linear interpolation. The read position advances by frequency * tableSize / sampleRate, so the note pitch changes the playback speed. The loop starts at sample 0 and ends just before sample 2048. When the position reaches the end, it wraps back around.

The shared ADSR envelope uses attack, decay, sustain, and release. waveEnd chooses a second table. Both tables use the same read position, and the sound gradually changes from the first to the second during the note. If waveEnd is missing, the wave stays the same. These tables hold short wave cycles.

40: Loop points6–8.7 s: the wave cycle repeats during the held note.
50: Cross-fading9–11.8 s: a chord changes from square to sine.

In the song, wavetable plays the bass. It changes pitch, uses all five waves, and cross-fades between tables. Each note loops its wave cycle and uses an envelope.
